These portraits are AI-generated, as described by the dataset publisher.
The game assigns fictional names. It resizes the source 1024x1024 PNG files
to 512x512 WebP images. It does not identify or depict named real people.

The upstream dataset card is preserved in artwork/one-million-faces/UPSTREAM_README.md.
At this revision the dataset repository has no separate LICENSE file or
copyright notice. This notice preserves its stated MIT license and source credit.
Detailed source keys, byte ranges and SHA-256 hashes are in the repository's
artwork/one-million-faces/manifest.json.
